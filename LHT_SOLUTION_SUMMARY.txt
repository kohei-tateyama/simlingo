LEFT-HAND TRAFFIC (LHT) CONVERSION - SOLUTION SUMMARY
==============================================================================

PROBLEM:
--------
Even after converting XML routes to LHT coordinates, CARLA still ran routes
in right-hand traffic (RHT) mode. The ego vehicle and NPC vehicles were 
driving on the right side of the road instead of left.

ROOT CAUSE:
-----------
The XML conversion script was only updating waypoint coordinates but NOT
configuring CARLA's Traffic Manager to use left-hand traffic rules.

Additionally, the leaderboard was using ITS OWN route parser (different from
scenario_runner), which wasn't reading the LHT metadata.

SOLUTION:
---------
1. ✓ convert_simlingo_xml_to_lht.py - Adds LHT metadata to XML root:
   - traffic_rules='left_hand'
   - lane_offset='-3.5'

2. ✓ scenario_runner/srunner/tools/route_parser.py - Reads metadata from XML
3. ✓ leaderboard/leaderboard/utils/route_parser.py - Reads metadata from XML (CRITICAL FIX!)
4. ✓ scenario_runner/srunner/scenarioconfigs/route_scenario_configuration.py - Stores metadata
5. ✓ leaderboard/leaderboard/leaderboard_evaluator.py - Applies metadata to Traffic Manager
6. ✓ leaderboard/leaderboard/leaderboard_evaluator_local.py - Applies metadata to Traffic Manager

HOW IT WORKS:
-------------
1. When you run convert_simlingo_xml_to_lht.py:
   - Converts waypoints to left lane positions
   - Converts scenario triggers to left lane positions  
   - Adds XML metadata: <routes traffic_rules="left_hand" lane_offset="-3.5">

2. When leaderboard loads a route:
   - Route parser reads the metadata from XML root
   - Stores it in RouteScenarioConfiguration object
   - Passes it to leaderboard evaluator

3. When leaderboard sets up a scenario:
   - Checks if config.traffic_rules == 'left_hand'
   - If yes, sets traffic_manager.global_lane_offset = -3.5
   - This shifts ALL NPC traffic to left lanes
   - Prints: "> Configuring LEFT-HAND traffic (lane_offset=-3.5)"

   - NPC vehicles should drive on LEFT side of road
   - Traffic should follow UK/Japan driving rules
